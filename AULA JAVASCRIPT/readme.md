# Exercícios de JavaScript

Esta pasta reúne exercícios práticos de JavaScript para trabalhar com eventos, manipulação de elementos HTML e atualização de conteúdo na página.

## Exercício 1 — Botão interativo

Criar um botão que muda de estado conforme a interação:

- azul quando o cursor está fora do botão;
- verde quando o cursor está sobre ele;
- vermelho quando clicado, exibindo a mensagem **“quebrei”**;
- depois de clicado, não deve mais mudar de estado.

**Conceitos praticados:** seleção de elementos do HTML, eventos de mouse e alteração de estilos e texto com JavaScript.

## Exercício 2 — Calculadora com botão

Criar uma calculadora com dois campos para os valores, um seletor para escolher entre as quatro operações básicas, uma área para exibir a resposta e um botão para realizar o cálculo.

**Conceitos praticados:** leitura de valores de campos, conversão de dados, condições para escolher a operação e apresentação do resultado na página.

## Exercício 3 — Calculadora automática

Modificar a calculadora do exercício anterior para remover o botão. A resposta deve ser recalculada automaticamente sempre que o valor de qualquer campo for alterado.

**Conceitos praticados:** eventos de alteração em campos e atualização dinâmica do resultado.
