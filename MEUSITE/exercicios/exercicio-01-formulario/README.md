# Exercício 1 — Formulário de pedido

## Objetivo

Simular um pedido de pizza com um formulário HTML.

## O que foi praticado

O formulário reúne campos de nome e e-mail, opções de tamanho, seleção de sabor, adicionais, data de entrega e observações. Também usa rótulos (`label`) para identificar os campos.

## Como abrir

Abra [index.html](index.html) em um navegador. O destino `teste.jsp` não existe neste projeto, então o formulário serve apenas para demonstrar os campos e não envia nem salva o pedido.
