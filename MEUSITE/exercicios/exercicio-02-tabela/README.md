# Exercício 2 — Tabela com células mescladas

## Objetivo

Praticar tabelas HTML com células que ocupam mais de uma coluna.

## O que foi praticado

O arquivo usa `<table>` para criar a tabela, `<tr>` para as linhas e `<td>` para as células. O atributo `colspan` define quantas colunas cada célula ocupa.

## Como abrir

Abra [index.html](index.html) em um navegador.
