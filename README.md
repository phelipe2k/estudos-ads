# Anotações de ADS

Estou organizando aqui alguns materiais e exercícios das aulas. Na pasta `MEUSITE`, estou praticando HTML e aprendendo a estruturar páginas com formulários, tabelas, imagens e links.

## Exercícios
- [Exercício 1 — Formulário](MEUSITE/exercicios/exercicio-01-formulario/index.html): pratiquei campos de texto, opções, caixas de seleção, data e botão de envio.
- [Exercício 2 — Tabela](MEUSITE/exercicios/exercicio-02-tabela/index.html): pratiquei a organização de informações em linhas, colunas e células mescladas.
- [Exercício 3 — Tabela de imagens com links para gatos e cachorros](<MEUSITE/exercicios/exercício-03-tabela com imagens/tabelaAnimais.html>): organizei imagens dos animais em uma tabela e adicionei links relacionados.
- [Exercício 4 — Mario](<MEUSITE/exercicios/exercício-4/pagina.html>): montei uma página sobre Mario usando títulos, parágrafos, listas, imagem e um link externo.

Esses exercícios estão me ajudando a conhecer melhor as tags HTML e a montar páginas de forma organizada.
