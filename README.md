# Anotações de ADS

Estou organizando aqui alguns materiais e exercícios das aulas. Na pasta `MEUSITE`, estou praticando HTML e aprendendo a estruturar páginas com formulários, tabelas, imagens e links.

## Exercícios
- [Exercício 1 — Formulário](MEUSITE/exercicios/exercicio-01-formulario/index.html): pratiquei campos de texto e e-mail, opções, caixa de seleção, data, observações e envio.
- [Exercício 2 — Tabela de gatos e cachorros](<MEUSITE/exercicios/exercício-03-tabela com imagens/tabelaAnimais.html>): organizei os animais em duas colunas e três linhas, usando cada imagem como link.
- [Exercício 3 — Tabela com células mescladas](MEUSITE/exercicios/exercicio-02-tabela/index.html): pratiquei a criação de linhas com diferentes quantidades de colunas usando `colspan`.
- [Exercício 4 — Página sobre Mario](<MEUSITE/exercicios/exercício-4/pagina.html>): pratiquei títulos, parágrafos, listas, imagem e link externo em uma página sobre o personagem.

Esses exercícios estão me ajudando a conhecer melhor as tags HTML e a montar páginas de forma organizada.
